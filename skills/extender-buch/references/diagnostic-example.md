# Exemplo: uma lista nova de álgebra linear

O livro já tem subespaços, núcleo, bases e mudança de coordenadas. A lista tem:

- **1(a):** provar que a imagem de uma transformação linear é um subespaço;
- **1(b):** provar que a transformação induzida no quociente pelo núcleo é um isomorfismo;
- **2:** decidir se um resultado sobre troca de base continua válido sem dimensão finita.

Leia o livro. Se ele só define a imagem e não pede a prova, classifique 1(a) como **teoria sem prática suficiente** e acrescente um exercício no capítulo de transformações. Se não define espaço quociente, classifique 1(b) como **pré-requisito faltante** e introduza classes e boa definição antes da fatoração. Se a mudança de base só é tratada por matrizes finitas, classifique 2 como **tópico faltante**; diferencie uma base de Hamel de um modelo finito por matrizes e verifique qual afirmação da lista realmente exige dimensão finita.

Para uma avaliação próxima, a rota de prioridade é imagem → classes laterais → boa definição → primeiro isomorfismo → limites de dimensão. A rota de aprofundamento inclui quocientes por outros subespaços, propriedades universais e contraexemplos. Acrescente variantes como “a regra ainda é bem definida se o subespaço não está contido no núcleo?”. Termine com um item misto sem indicação da técnica. Registre o que a lista não permite inferir sobre a avaliação e preserve as tentativas anteriores.
